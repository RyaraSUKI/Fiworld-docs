# 鼎星 · Fiworld

> 个人架空世界观创作仓库：以「鼎星 / 北骅人民共路国」为主线，旁及衍生世界「URG / 草联邦共和国」与独立文明「凤石」，外加现实侧的社群、Minecraft 服务器与文字游戏工具。
>
> 全部内容为 Markdown 设定文档，用 Git 跨设备同步。内容纯属虚构，与现实无任何关联。

---

## 一、这是什么

这不是一个软件项目，而是一份**持续生长的设定集**：一个架空行星上的一国民众、一套纪年历法、一条从部落时代写到信息时代的历史线，以及围绕它长出来的新闻体裁（NSX）、行政区划、宗教、语言与亚文化。

写作方式是「边玩边写」——设定服务于社群跑团（鼎星群）的文明扮演，因此文档里同时存在**已定稿的正史**、**AI 生成的草稿**、**旧版快照**与**只写了标题的规划**。分辨它们比读内容本身更重要，见 [第七节](#七文档状态与可信度)。

- **主舞台**：鼎星系 → 鼎星（行星）→ **北骅人民共路国**（Norse，简写 NS），赤骅民族国家。
- **核心设定**：骅历九时节、多党协商制、彼岸教、示音字、依姆莱德（虚拟空间）、NSX 新闻体。
- **衍生世界**：**URG / 草联邦共和国**（和平向，《依雅莱旅记》发生地），其中「云生省」已整理出分模块介绍。
- **现实载体**：鼎星群（社群）、鼎盛村（Minecraft 服务器）、烟火终端 Fiternimal（HTML 文字游戏工具）。

## 四、主世界观：鼎星与北骅

### 4.1 层级与地理

世界是**三层嵌套**的：**鼎星系**（多文明并存的星际舞台，有「万国」「东北联邦」「汉」等外部势力）→ **鼎星**（主舞台行星，三颗卫星，春华时有「连星现象」）→ **北骅人民共路国**（赤骅民族国家，占有赤骅岛、燕依岛、煌龙群岛）。

### 4.2 北骅基本盘

- **首都**碧澄都；经济枢纽靛都、滨川；货币**梦路币**（smb）。
- **政体**：北方共路党领导的多党协商制，三会（人民代表大会 / 政治协商会议 / 府部参议选举会议），改革后元首为四年任期代表主席。
- **文化**：彼岸教、彼岸次元亚文化、示音字（表音文字，文言部规范）、依姆莱德虚拟空间、电波塔通信网。
- **行政区划**：赤骅岛（碧澄都、滨川、二通、汀凌、铭义 + 江川 / 滨山 / 江北 / 垠原 / 滩底五省）、燕依岛（靛都、科发、架山 + 谷川 / 山中 / 山北三省）、煌龙群岛（新西岛市等）。

### 4.3 骅历：九时节

以地球阳历为基准，一年九时节，长节 2 个月、短节 1 个月，短节 2 期、长节 3 期，一期 20 日：

| 阳历 | 时节 | 阳历 | 时节 |
|---|---|---|---|
| 12.28–1.27 | 新来时 | 6.28–7.27 | 仲夏时 |
| 1.28–2.27 | 雪融时 | 7.28–9.27 | 炎阳时（长） |
| 2.28–4.27 | 春华时（长） | 9.28–10.27 | 叶染时 |
| 4.28–5.27 | 光茂时 | 10.28–12.27 | 冰望时（长） |
| 5.28–6.27 | 鸣蝉时 | | |

写法 `'C1.15` 即春华时首期 15 日；**骅历与阳历只对齐月份，不能换算年日**。岁末为「告岁末时」。

### 4.4 历史主线

`北骅历史 新.md` 给出的是**事件链**：部落时代 → 早期部落联盟 → **大融**（首个正统政权，原始共和）→ 昆川之战两岛统一 → 世袭化 → **宏**（弥生氏，颁《宏工典》、分封诸侯、彼岸教产生）→ 青铜与乐府新章运动 → **隆**（BC1800 丫幼代弥，隆中新制）→ 睦末战国 → **辉朝**（封建帝国，《大央骅骝律典》）→ 近代（列强介入、共路主义启蒙、第一次工业革命）→ 共路革命与建设 → 信息时代。

⚠️ `北骅待处理.md` 另附一套带绝对年份的年表，属 AI 生成的草稿；两套年表互相冲突，**未定稿前不要引用具体年份**。

### 4.5 NSX：世界观内的新闻

**NSX = Norse X News（北骅騵讯社）**，栏目有今讯速晓 / 今讯夜晓 / 急讯速晓 / 号外 / 政讯速晓 / 特别刊 / 骅音世晓。写法是把现实新闻的机构名、政策口吻、灾难应对流程平移到架空国家，模板固定：

```
### NSX 北骅今讯速晓
#### 今天是 11.5，约骅历 冰望时
> 今天的新闻是
- （四到六条政经 / 民生 / 文化 / 科技新闻）
```

`NSX_DS.md` 收录 15 期，从冰望时跨到雪融时，含「极寒协议」「千灯映雪」「雪融俳句集」等条目。

## 五、衍生世界与外部文明

- **URG / 草联邦共和国**：经「维度航班」抵达的和平向维度，《依雅莱旅记·草国篇》的发生地。目前整理最完整的是**云生省**——草国西北的偶像文化省，面积 248,516 km²，省会依云城，下辖 **14 个「偶联自治市」**，实行**联合会制 + 人类责任 AI 辅助民主制**（AI 给建议、人负责），以邦多利文化、地下偶像、二偶三源著称。`URG/云生分模块介绍.md` 分 12 个模块，末尾列了 10 项数据缺口与 7 条写作钩子。
- **凤石（PhoΣize）**：独立文明设定，四大地带（南部农耕 / 北部沙漠 / 东部畜牧 / 西部沿海），由部落联盟发展为君主专制奴隶制帝国「凤石里」。现存于 `归档/凤石.md`。
- **外部势力**：东北联邦、汉、万国、CCFP、星际贸易组织等目前只有零星提及，尚无设定页。

## 八、协作约定

本仓库支持多设备多人（其实是多设备一个人）接手，规矩写在 `同步说明.md`：

1. **收工或换设备前必须同步**：`bash sync.sh "做了什么" "下一步该做什么"`。
2. 脚本会在 `同步说明.md` 第九节末尾追加一条变更记录，再提交、`pull --rebase`、推送。
3. **第九节只追加，不改写**——那是交接日志，下一手靠它接续。
4. 每台设备先设一次本地设备名：`git config sync.device "设备名"`（本地配置，不随仓库走）。
5. 空目录靠 `.gitkeep` 占位；令牌、私钥一律不进仓库。
6. Windows 上若无 `bash`，可用 Git Bash 全路径调用；提交信息含中文时用 `git commit -F 文件` 避免编码截断。

## 九、当前缺口（摘自《世界观总览》第八节与《云生分模块介绍》第十模块）

1. **年表**：两套历史纪年冲突，需定稿后才可引用年份。
2. **行政体系**：`北骅行政体系.md` 仍是空壳，省级职能与「央平委员会—三会—常委会」关系图待画。
3. **历法**：旧稿有「八时节」说法，需统一为九时节。
4. **国名**：历史上出现过多种国名称呼，需一份「正式名 / 简称 / 历史名」对照。
5. **教育大纲**：`画饼/` 两份只有标题。
6. **外部势力与其它文明**：缺设定页，建议与主世界观分级存放（如 `外文明/`）。
7. **云生省**：人口、依云城、执政机构、14 个偶联自治市名单全缺（人口最要紧）。
8. **文件治理**：`归档/` 与 `deepseek帮我写/` 的重复副本需清理或明确「以根目录为准」。

## 十、快速开始

```bash
git clone git@github.com:RyaraSUKI/Fiworld-docs.git
cd Fiworld-docs
git config sync.device "设备名"
bash sync.sh --local   # 确认仓库干净、脚本可用
```

然后从 `世界观总览.md` 读起；要接着写，就看该文件第七节的文件索引与第九节的缺口清单。
